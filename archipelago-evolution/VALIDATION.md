## 重复实验的实际输出

种子 `ISLAND-PAIR-01|replicate|1` 至 `…|20`，各100代。
以下是观察结果，不是要求所有运行必须满足的测试断言。

| 实验 | 20对平均差值A−B | 末代平均N：A / B |
| --- | ---: | ---: |
| 保持迁移 / 关闭迁移，D | −0.104508 | 204.90 / 252.25 |
| 有选择 / 无选择，M | −0.078500 | 244.55 / 267.25 |
| 无瓶颈 / 瓶颈，H | +0.070564 | 267.05 / 267.05 |

浏览器重复运行第三组得到相同汇总：17次H(A)>H(B)，3次方向相反，20对均有定义、无全群岛灭绝。
数量可能在配对随机流下重新同步，这不代表基因组成同步。平均结果也不保证任一种子都符合预期。

## 使用范围

检查能发现实现错误，不能证明模型是真实生态过程的完整描述。无物种数据校准、无生殖隔离机制，不能据此判断物种形成或直接作保护决策。
