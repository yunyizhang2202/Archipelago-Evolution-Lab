# 群岛进化实验室

双击 `dist/index.html` 即可离线使用，不需要安装依赖或接入外部服务。

- 演化现场：可干预环境、突变、迁移、选择强度与种群瓶颈。
- 对照实验：三个预设实验，完全相同的祖先及配对随机种子，支持10–30次独立重复及CSV导出。
- 模型与验证：完整方程、假设、局限，以及直接运行同一模拟引擎的八项检查。

## 三分钟体验

1. 开始演化，查看平均体色随世代的变化；点击一个个体查看基因组。
2. 将青苔岛的最适体色改为0.85，观察数量与性状变化。
3. 运行第三个对照实验的20次重复，比较瓶颈后数量与基因多样性的恢复。

## 独立检查

已安装 Node.js 的环境可运行 `node tests/model.test.mjs`。
科学规则测试不依赖任何第三方库。实际浏览器交互检查记录见 `VALIDATION.md`。

## 复现实验记录

现场导出的 `archipelago-replay.json` 包含种子、初始参数、操作序列及终止世代。
页面内置的引擎可重放：

```js
const replayed = EvoLab.replay(record.seed, record.initialConfig, record.events, record.until);
archipelago.setWorld(replayed);
```

渲染不使用模拟的随机流；同一种子、参数与操作序列会生成相同的基因型与个体身份。
三个预设实验独立于现场参数。导出日志保留全部操作，界面仅展示最近100次干预；曲线展示最近300代。

## 模型范围

24个二等位位点的单倍体无性群体，12个位点控制每种表型，完全连锁。
密度制约繁殖采用 Beverton–Holt 形式并叠加泊松人口随机性。
后代数量不是固定N；K是中性确定性平衡而非硬上限。
灭绝岛屿只能通过迁入重新定殖；全群岛灭绝后无自动补充。
不模拟生殖隔离，性状分化不能解释为物种形成。

这是教学模型，未由任何真实物种数据校准，不能直接用于保护决策或生态预测。

## 文件

- `dist/model.js`：纯模拟引擎及可运行不变量检查。
- `dist/view.js`：岛屿、个体、轨迹与分布图；图形状态来源于同一世界。
- `dist/app.js`：交互控制、成对实验、重复结果、导出与WebMCP渐进支持。
- `dist/icons.js`：Lucide图标库，ISC许可。
- `tests/`：可重跑的模型检查及窄屏布局测试页面。

选择强度0时环境不影响繁殖，但描述性失配指标仍可变化。
H是平均2p(1−p)的描述值，没有小样本无偏修正，不能与实际杂合个体比例混淆。
