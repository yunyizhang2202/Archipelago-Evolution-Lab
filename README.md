# 群岛进化实验室 | Archipelago Evolution Lab
一个中文交互式教学模拟，探索三个岛屿上的遗传、突变、自然选择、遗传漂变与迁移。

An interactive teaching simulator with a Chinese interface, exploring inheritance, mutation, natural selection, genetic drift and migration across three islands.

## 功能 | Features
- 调整环境与演化参数，触发种群瓶颈。  
  Adjust environments and evolutionary parameters, and trigger population bottlenecks.
- 查看个体性状、种群变化与实时图表。  
  Inspect individual traits, population changes and live charts.
- 重复运行配对实验，比较不同干预的结果。  
  Run replicated paired experiments to compare interventions.

## 使用 | Usage
下载并解压项目，保留完整 `dist` 文件夹，用浏览器打开 `dist/index.html`。无需安装或联网。

Download and extract the project, keep the entire `dist` folder, and open `dist/index.html` in a browser. No installation or internet connection required.

## 说明 | Note

这是简化的教学模型，不用于真实生态预测；性状分化不等于物种形成。项目由作者提出需求，借助 OpenAI AI 工具开发。

This simplified teaching model is not intended for real-world ecological prediction; trait divergence does not imply speciation. Developed with OpenAI AI tools from the author's requirements.
